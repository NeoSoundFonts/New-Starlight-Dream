# New-Starlight-Dream
新星光之梦。将各种自由文化音色库混合而成的通用音色库。<br>
A soundbank that made for Free Cultral Works. Each sample set uses different libre sources.

[源文件<br>Source Files](https://github.com/NeoSoundFonts/NSD-Source-Files)

[下载地址<br>Download Link](https://archive.wohlsoft.ru/_User/Yingchun%20Soul/Sample%20Libraries/New%20Starlight%20Dream.sf2)

本仓库提供精简版，可通过Clone/Download Zip下载。该版本只导入Creative Commons 0 1.0授权协议发布的采样，并按照CC0授权协议发布。<br>
Lite Version is provided in this repo. Clone/Download Zip to download it. This version is licensed under Creative Commons 0 1.0 and only imports CC0-licensed samples.

音色库例外：您可以使用本音色库创作任何类型的音乐（不需要按GPL授权协议发布），但对于部分预设来说，需要注明原作者。需要注明原作者的预设用“=”前缀表示。<br>
Exception: You can use this soundbank for compose musics whatever you want (Including non-GPL licensed musics)! Besure to give credit if you used partial presets, these will be prefixed with "=".
